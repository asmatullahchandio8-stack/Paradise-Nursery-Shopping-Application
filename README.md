# Paradise Nursery 🌿

A responsive houseplant shopping application built with React, Redux Toolkit, and Vite.

## Features

- Landing page with background image and company information
- Product listing page
- 3 plant categories
- 9 unique houseplants
- Add to Cart functionality
- Disabled Add to Cart button after selection
- Dynamic cart quantity in navbar
- Redux Toolkit shopping cart state
- Increase and decrease item quantities
- Delete items from cart
- Total plant count
- Total cart cost
- Checkout "Coming Soon" message
- Continue Shopping button
- Responsive design
- GitHub Pages deployment ready

## Technologies

- React
- React Router
- Redux Toolkit
- React Redux
- Vite
- Lucide React
- CSS

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

First create a public GitHub repository and push this project.

Then run:

```bash
npm install
npm run deploy
```

The generated `dist` folder is deployed to the `gh-pages` branch.

## Project Pages

- `/` - Landing page
- `/plants` - Product listing
- `/cart` - Shopping cart
